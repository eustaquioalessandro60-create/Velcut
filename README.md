# IDMCifras — Ecossistema Zuri Rimane

Scaffold Flutter multi-plataforma (Web + Mobile) com design Navy (#0A1122) e Dourado (#D4AF37).

Inclui módulos e telas placeholder para:
- Cadastro Único
- Feed Infinito
- IDM Streams (Loja + Mercado Livre)
- Universal Ads (placeholder)
- Bank Invest (placeholder)
- Registro Legal
- Carteirinha de Músico
- Fã Clube
- Caravana IDM
- Flow Business
- Rádio
- Podcast

Como rodar:
1. Instale Flutter SDK (inclui suporte web).
2. flutter pub get
3. flutter run -d chrome  (para web) ou flutter run em mobile

Este repositório contém um scaffold com serviços mock; substitua serviços por integrações reais conforme necessário.
